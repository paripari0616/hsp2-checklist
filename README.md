# 高度人才 1 号转 2 号材料清单

一个用于整理日本「高度専門職 1 号」转「高度専門職 2 号」申请材料的轻量网页工具。

## 功能

- 按个人条件生成材料清单
- 按准备方区分本人、公司、行政窗口、线上办理
- 提醒周末和行政窗口工作日限制
- 支持勾选进度和打印保存

## 信息来源

本工具基于日本出入国在留管理厅公开资料整理。申请前请以官方最新页面和管辖入管要求为准。

- 出入国在留管理厅：在留資格「高度専門職」
- 出入国在留管理厅：高度人材ポイント制
- 国税厅：納税証明書の交付請求手続

## 注意

本工具只用于准备辅助，不构成法律意见，也不能保证审查结果。提交后，入管可能要求追加资料。
